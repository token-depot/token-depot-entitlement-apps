# Notice

This repository contains public reference apps for Token Depot-issued KRC-20 CA issue-mode entitlement tokens.

The apps are read-only. They use public indexer APIs to retrieve token metadata, wallet balances, and future operation proofs. They do not require or request private keys, seed phrases, mnemonics, keyfiles, passphrases, wallet unlock, signing, Token Depot admin access, AWS credentials, or hosted Token Depot infrastructure.

Token Depot-issued status is not inferred from public metadata alone. It is assigned only when a CA appears in the Token Depot known-CA registry provided in this repository or another approved public Token Depot registry.
